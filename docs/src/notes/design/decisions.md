## 未決事項（作者が決める）

実装担当はここを勝手に決めない。作者が決めたら、「決定」欄に日付と結論を書き、関係する WP の仕様を直す。実装担当は、その後に着手する。
「止まる作業」の P・U・F・PL で始まる ID は [roadmap-v0.3-v0.5.md](roadmap-v0.3-v0.5.md) の提案の番号で、
v0.2 実行計画書のタスク ID（P1・P2 など）とは別のもの。ただし U5・U6・U8 は roadmap になく、
この文書群には定義がない。出典は未確認。
